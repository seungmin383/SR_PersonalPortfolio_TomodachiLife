1. Vertex 구조체 정의

#Engine Struct 에 정의함

정점 구조체를 정의했다면 
정점의 구조체의 각 성분이 어떤 용도인지 DX3D에게 알려줘야됨

-> ID3DllInputLayout 형식의 input layout 객체
D3D11_INPUT_ELEMENT_DESC 구조체로 이루어진 배열을 통해 구축한다.

typedef struct D3D11_INPUT_ELEMENT_DESC
    {
    LPCSTR SemanticName;                 
    UINT SemanticIndex;
    DXGI_FORMAT Format;
    UINT InputSlot;
    UINT AlignedByteOffset;
    D3D11_INPUT_CLASSIFICATION InputSlotClass;
    UINT InstanceDataStepRate;
    } 	D3D11_INPUT_ELEMENT_DESC;

LPCSTR SemanticName;
성분에 부여된 문자열 이름
-> 정점 쉐이더에서 semantic 이름으로 쓰이므로 반드시 유효한 변수 이름
semantic -> 정점 구조체의 성분을 정점 셰이더 입력 서명과 대응시키는 역할

UINT SemanticIndex;
semantic에 부여된 색인
-> 정점 구조체에 텍스쳐 좌표가 여러 개 있는 경우,
semantic 이름을 부여하는 대신 색인을 통해 각각을 구별(지정 안하면 0)

DXGI_FORMAT Format;
정점 성분의 자료형식을 나타냄
ex) DXGI_FORMAT_R32_FLOAT 등

UINT InputSlot;
이 성분의 자료가 공급될 정점 버퍼 슬롯의 색인

UINT AlignedByteOffset;
InputSlot을 하나만 사용하는 경우 
정점 구조체 시작위치와 이 정점 성분의 시작 위치 사이의 오프셋(바이트)

ex)
struct Vertex2
{
XMFLOAT3 Pos;       -> 0byte offset
XMFLOAT3 Normal;    -> 12byte offset
XMFLOAT2 TexO;      -> 24byte offset 
XMFLOAT2 Tex1;      -> 32byte offset
}


D3D11_INPUT_CLASSIFICATION InputSlotClass;
D3D11_INPUT_PER_VERTEX_DATA를 지정
다른 값은 이후 인스턴싱에 사용

UINT InstanceDataStepRate;
인스턴싱에 사용
