# Input Assembler ===================================================
-> 메모리에서 기하 자료(정점들과 색인들)를 읽어서
기하학적 기본도형(삼각현, 선분 등)을 조립하는 단계

1. 정점이란?
공간적 위치를 담고있는 점
그러나 DX에서는 
조명을 위해 법선벡터나
텍스쳐를 위해 텍스쳐좌표를 추가해서 더 복잡한 렌더링 효과를 낼 수 있다.

2. 정점버퍼
정점들은 정점버퍼라는 DX3D 자료구조 안에 담겨서 렌더링 파이프라인에 묶인다.

IASetPrimitiveTopology(D3D11_PRIMITIVE_TOPOLOGY Topology)
-> IA가 정점들을 어떤 Primitive로 묶어서 그릴지를 지정해주는 함수
-> 정점 / 인덱스 버퍼의 해석 규칙을 바꿔준다.

3. 색인이란?
아 이게 인덱스구나

#Vertex Shader =========================================================
->IA에서 조립한 기본도형의 정점 하나를 받아서 정점 하나를 출력하는 함수
프로그래머가 직접 VS함수의 내용을 작성해서 GPU에 제출할 수 있음
-> 변환, 조명, 변위매핑 등 수많은 특수효과를 수행할 수 있음

1. Local -> World로의 변환
각 인스턴스마다 물체의 정점 및 색인자료를 중복하는 것은 낭비가 심하다.

- 인스턴싱
물체의 Local 좌표를 기준으로 복사본 하나만 저장해두고,
물체의 개별 인스턴스마다 World행렬을 다리게 설정해서 그리는 기법
-> 이런 인스턴싱을 하드웨어 안에서(한번의 그리기 호출로) 일어나게
하는 기법이 '하드웨어 인스턴싱'

2. 뷰스페이스
카메라에 Local좌표를 부여한다 -> View Space 

XMMATRIX XMMatrixLookAtLH ( // 계산된 시야 행렬 v를출력
FXMVECTOR vEye,		// 입력카메라위치 Q
FXMVECTOR vAt,		// 입력 대상 점 T
FXMVECTOR vUp) ;	// 입력 세계상향 벡터 j

-> view 행렬 구하는 방법

3. 투영과 동차 절단 공간
카메라가 바라보는 공간영역 / 하나의 절두체로 정의된다.

절두체 안의 3차원 기하구조를 2차원 투영 창으로 투영
물체의 3차원 깊이가 증가함에 따라 투영된 크기가 줄어들어야됨
-> 이를 위해 평행선이 하나의 소실점으로 수렴하는 방식으로 이루어져야됨

- 정점의 투영
원점과 투영 창 사이의 거리 d를 구하는 방법 (수직 시야각을 a로 둔다)
-> d는 투영 창의 높이가 2일 때 수직 시야각이 a가 되는 투영 창의 거리
tan(a / 2) = 1 / d -> d = cot(a / 2)

점 (x, y, z)가 주어졌을 때 
이를 투영평면 z = d에 투영한 점 (x', y', d)를 구하고자 한다.

x' / d = x / z
-> x' = x*d / z = x*cot(a / 2) / z = x / z*tan(a / 2)
-> y' = y*d / z = y*cot(a / 2) / z = y / z*tan(a / 2)

-r <= x' <= r
-1 <= y' <= 1
n <= z <=f
일 때 절두체 안에 존재한다.

- NDC (정규화된 장치 좌표)
위에서는 투영된 점의 좌표를 시야공간에서 계산했다.
시야공간에서 투영창은 h = 2, w = 2r이다.

이때 투영창의 크기가 종횡비r에 의존하게 되고,
하드웨어가 투영창의 크기에 관여하는 연산(투영창을 후면버퍼에 투영)을
수행할 때 하드웨어에 종횡비를 알려줘야 하는 문제가 발생한다.

-> x'를 -r, r 구간에서 -1, 1 구간으로 비례시킴으로 해결할 수 있다.
이 과정을 거친 x, y 좌표를 NDC 라고 한다

x' / d = x / z
-> x' = x*d / z = x*cot(a / 2) / z = x / r*z*tan(a / 2)
-> y' = y*d / z = y*cot(a / 2) / z = y / z*tan(a / 2)

NDC좌표에서는 h = 2, w = 2이다.

-투영 변환을 행렬로
위에서 구한 투영변환은 비선형이므로 행렬표현을 할 수 없다.
대신 공식을 선형과 비선형으로 나눠서 해결할 수 있다.

비선형 -> z 나누기
임의의 점 (x, y, z, 1)에 투영행렬을 곱하면
(x / r*tan(a / 2), y / tan(a / 2), Az + B, z)의 점이 나오는데

w = z로 나누면 
(x / r*z*tan(a / 2), y / z*tan(a / 2), A + (B / z), 1)

- 정규화된 깊이 값
DX에서는 투영된 x, y 좌표가 정규화 된 범위이길 요구한다.
-> 깊이 값(z)도 마찬가지로 정규화 된 0 ~ 1 범위이길 요구한다.
-> 이를 위해 n,f 구간을 0,1로 사상하는 순서보존함수 g(z)를 만든다
순서보존함수 -> 깊이 값을 변환 해도 값들의 상대적 관계는 유지된다

g(z) = (f / f - n) - (n*f / (f - n)*z)

-XMMatrixPerspectiveFovLH
-> 원근투영 행렬을 구축해준다
